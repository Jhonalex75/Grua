📘 Referencia Técnica: Selección de Grúas Móviles

La app integra conceptos del estudio académico "Optimization Algorithm for Selection and on Site Location of Mobile Cranes" (Al-Hussein et al., 2005), que propone un algoritmo de optimización para seleccionar la mejor configuración de grúa según el sitio, la carga y los obstáculos.

  • Permite seleccionar radios de izaje y longitudes de pluma óptimos (Algoritmo-2).
  • Considera obstáculos como edificaciones cercanas y radios de giro.
  • Integra una base de datos de grúas (D-Crane) y un módulo de optimización basado en Excel Solver.
