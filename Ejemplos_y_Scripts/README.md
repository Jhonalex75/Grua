# Ejemplos y Scripts Adicionales

Esta carpeta contiene materiales complementarios al contenido principal de los capítulos. Aquí encontrarás ejemplos prácticos, experimentos, recursos visuales y aplicaciones que te ayudarán a profundizar en los métodos numéricos y su aplicación en ingeniería.

## Estructura interna

- **Notebooks_y_Scripts_Python/**: Notebooks (`.ipynb`) y scripts de Python (`.py`) con ejemplos, modelaciones, cálculos y experimentos numéricos. Incluye recursos avanzados como el script de aplicación web Flask (`# requirements.py`).
- **Datos_y_Hojas_Calculo/**: Hojas de cálculo y archivos de datos usados en los ejemplos y notebooks (Excel, CSV, etc.).
- **Graficos_e_Imagenes/**: Imágenes, gráficos y recursos visuales generados o utilizados en los ejemplos.
- **Ejemplos_Web/**: Archivos HTML y JS para ejemplos interactivos, aplicaciones web sencillas y presentaciones.

## Ejemplo destacado

- **# requirements.py**: Ejemplo avanzado de una aplicación web (Flask) para gestión de equipos y mantenimiento. No es un archivo de dependencias, sino un recurso práctico para quienes deseen explorar aplicaciones web en ingeniería.

## ¿Cómo usar estos recursos?

- Abre los notebooks (`.ipynb`) con Jupyter o Google Colab.
- Ejecuta los scripts `.py` con Python desde la terminal.
- Abre las hojas de cálculo con Excel o LibreOffice.
- Visualiza los archivos `.html` y `.js` en tu navegador para ver ejemplos interactivos.
- Consulta los gráficos e imágenes como referencia visual.
