# Recursos Gráficos

En esta carpeta encontrarás imágenes, diagramas, gráficos y otros recursos visuales que complementan los capítulos y ejemplos del proyecto.

---

## ¿Qué puedes encontrar aquí?

- Imágenes ilustrativas de conceptos matemáticos y de ingeniería.
- Diagramas de flujo, organigramas y esquemas.
- Gráficos generados por los scripts o notebooks del repositorio.

---

## ¿Cómo usar estos recursos?

- Puedes visualizar o descargar cualquier imagen para tus estudios o presentaciones.
- Algunos recursos son utilizados automáticamente por el programa visual (GUI) o los notebooks.
- Si usas estos recursos en tus propios materiales, por favor cita este repositorio como fuente.

---

## Nota

Si tienes imágenes nuevas que puedan enriquecer el aprendizaje, puedes agregarlas aquí siguiendo la misma organización.
