# Chapter 4: Introduction to Basic Widgets

A window is just an empty container. To make our application useful, we need to add interactive elements called **widgets**.

In this chapter, you will learn how to create, configure, and manage the three most fundamental widgets in any GUI application.

---

### What You Will Learn

1.  **`Label`:** How to display static text or information to the user.
2.  **`Entry`:** How to create a text box that allows users to input single-line data.
3.  **`Button`:** How to add a clickable button that triggers an action.
4.  **Basic Interaction:** How to write a function that reads data from an `Entry` widget and displays it in a `Label` when a `Button` is clicked.

### Running the Script

Execute the `basic_widgets_app.py` script in this folder to see these widgets in action. You will be able to type your name into a box and click a button to see a personalized greeting.

```bash
python basic_widgets_app.py
```
