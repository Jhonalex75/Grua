# Capítulo 1: Fundamentos de Python para Métodos Numéricos

Este capítulo introduce los conceptos esenciales de Python necesarios para la programación de métodos numéricos. Está diseñado para ingenieros mecánicos sin experiencia previa en programación, enfocándose en la intuición y la aplicación práctica.

## Contenido Teórico

Python es un lenguaje de programación versátil y fácil de aprender, ideal para la computación científica. Para los métodos numéricos, es crucial entender cómo Python maneja los datos y las operaciones básicas. NumPy y Matplotlib son bibliotecas fundamentales que extienden las capacidades de Python para trabajar eficientemente con números y visualizar resultados.

*   **Variables y Tipos de Datos:** Cómo almacenar diferentes tipos de información (números enteros, decimales, texto, valores lógicos).
*   **Operaciones Básicas:** Realizar cálculos aritméticos y lógicos.
*   **Estructuras de Control de Flujo:** Cómo hacer que el programa tome decisiones (`if/else`) y repita tareas (`for/while`).
*   **Funciones:** Organizar el código en bloques reutilizables para tareas específicas.
*   **NumPy:** La base para la computación numérica de alto rendimiento en Python, especialmente para trabajar con arreglos (vectores y matrices).
*   **Matplotlib:** La biblioteca estándar para crear gráficos y visualizar datos, esencial para interpretar resultados de simulaciones.

## Ejercicios Prácticos

Cada ejercicio es un script de Python (`.py`) con comentarios detallados y ejemplos relevantes para la ingeniería.

### `ejercicio_1_variables_tipos_operaciones.py`

*   **Descripción:** Introduce las variables, los tipos de datos fundamentales (enteros, flotantes, cadenas de texto, booleanos) y las operaciones aritméticas básicas. Explica cómo Python almacena y manipula la información.
*   **Conceptos Clave:** Asignación de variables, `int`, `float`, `str`, `bool`, suma, resta, multiplicación, división, potencia, división entera, módulo.

### `ejercicio_2_condicionales.py`

*   **Descripción:** Explora las sentencias condicionales (`if`, `elif`, `else`), que permiten a los programas tomar decisiones basadas en condiciones. Fundamental para la lógica de control en simulaciones.
*   **Conceptos Clave:** `if`, `elif`, `else`, operadores de comparación (`>`, `<`, `>=`, `<=`, `==`, `!=`), lógica booleana.

### `ejercicio_3_bucles.py`

*   **Descripción:** Presenta los bucles (`for` y `while`), herramientas esenciales para repetir tareas. Se explica cuándo usar cada tipo de bucle y cómo controlar su flujo con `break` y `continue`.
*   **Conceptos Clave:** Bucle `for`, `range()`, bucle `while`, `break`, `continue`, iteración sobre listas.

### `ejercicio_4_funciones_numpy_matplotlib.py`

*   **Descripción:** Cubre la creación y uso de funciones para organizar el código. Introduce NumPy para el manejo eficiente de arreglos numéricos (vectores y matrices) y Matplotlib para la visualización básica de datos.
*   **Conceptos Clave:** `def` (definición de funciones), `return`, `import numpy as np`, `np.array`, operaciones con arrays, `import matplotlib.pyplot as plt`, `plt.plot`, `plt.scatter`, `plt.title`, `plt.xlabel`, `plt.ylabel`, `plt.grid`, `plt.legend`, `plt.show()`.
