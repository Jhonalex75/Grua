# Datos y Documentos

En esta carpeta encontrarás archivos de datos, hojas de cálculo, bases de datos y documentos de referencia utilizados en los capítulos, ejemplos y aplicaciones del proyecto.

---

## ¿Qué puedes encontrar aquí?

- Archivos Excel, CSV y otros formatos de datos para análisis y ejercicios.
- Bases de datos utilizadas por scripts o aplicaciones del repositorio.
- Documentos PDF de referencia, manuales y bibliografía relevante.

---

## ¿Cómo usar estos recursos?

- Los scripts y notebooks pueden leer directamente estos archivos para sus ejemplos y ejercicios.
- Puedes consultar los documentos PDF y hojas de cálculo como material de apoyo.
- Si agregas nuevos datos, por favor usa nombres descriptivos y documenta su propósito.

---

## Nota

Estos recursos son de libre uso para fines educativos. Si usas datos de terceros, cita la fuente correspondiente.
