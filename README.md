# Numerical Methods and GUI Development: A Tutorial

Welcome! This project is a hands-on tutorial designed to teach the fundamentals of numerical methods and how to build interactive Graphical User Interfaces (GUIs) in Python using the Tkinter library.

This tutorial is for students, engineers, and hobbyists who want to bridge the gap between theoretical algorithms and practical, interactive applications.

---

### Learning Objectives

By following the chapters in order, you will learn:

-   **Professional Code Structure:** How to organize a Python project with clear, reusable modules.
-   **GUI Development:** How to build clean, modern, and user-friendly interfaces with Python's standard `tkinter` and `ttk` libraries.
-   **Separation of Concerns:** The critical importance of separating algorithmic logic from the user interface.
-   **Numerical Methods:** Practical implementation of foundational algorithms like the Bisection Method and the 4th-Order Runge-Kutta method.
-   **Data Visualization:** How to embed `matplotlib` plots directly into a GUI for dynamic and interactive data analysis.

### How to Use This Tutorial

The project is organized into chapters, each in its own numbered folder. It is highly recommended to go through them sequentially, as each chapter builds upon the concepts of the previous one.

-   **Start with the `README.md` in each folder.** It explains the goals and key concepts of that chapter.
-   **Examine the Python scripts (`.py`).** They are heavily commented to be as didactic as possible.
-   **Run the scripts** to see the concepts in action.

### Dependencies

To run all the examples in this tutorial, you will need to install the required Python libraries. You can do this easily by using the provided `requirements.txt` file:

```bash
pip install -r requirements.txt
```

Enjoy the journey from theory to application!
