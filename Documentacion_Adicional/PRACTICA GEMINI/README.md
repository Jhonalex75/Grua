# Práctica Gemini

Esta carpeta contiene ejemplos de hojas de vida en formato Lua, utilizadas como práctica o demostración de formato.

## Archivos

- `hoja de vida.lua`, `hojadevida.lua`: Archivos de ejemplo de hoja de vida en formato Lua.
- `MANT_1.html`: Interfaz web relacionada con mantenimiento (posiblemente un formulario o reporte).

## Uso

- Los archivos `.lua` pueden abrirse con cualquier editor de texto para ver su estructura.
- El archivo `.html` puede visualizarse en un navegador web.

> **Nota:** Estos son ejemplos de formato y pueden requerir ajustes para su uso en producción.
