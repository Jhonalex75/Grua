# Cálculo de Áreas y Tuberías

Esta carpeta contiene herramientas web interactivas para el cálculo y análisis de tuberías en ingeniería. Los archivos HTML incluyen calculadoras para dimensionamiento, pérdidas de carga y otros parámetros hidráulicos relevantes.

## Archivos principales

- `CALCULO TUBERIA V2.html`, `V3.html`, `V4.html`: Versiones de calculadora de tuberías con mejoras progresivas.
- `CALCULO TUBERIA ENTERRADA REV1.html`: Herramienta específica para tuberías enterradas.
- `Management.html`, `Management_1.html`, `Management_2.html`: Interfaz de gestión de cálculos de tuberías.

## Uso

1. Abre cualquiera de los archivos `.html` en tu navegador web.
2. Sigue las instrucciones en pantalla para ingresar los parámetros requeridos.
3. La herramienta calculará automáticamente los resultados solicitados.

> **Nota:** Estas herramientas son de referencia y pueden requerir validación para casos de uso específicos.
