# Métodos Numéricos - Ejemplos

Esta carpeta contiene implementaciones de métodos numéricos fundamentales para la resolución de ecuaciones diferenciales ordinarias (EDOs).

## Contenido

- `RUNGE KUTTA.py`: Implementación del método de Runge-Kutta de cuarto orden para resolver EDOs.

## Uso

1. El script `RUNGE KUTTA.py` puede ejecutarse directamente con Python.
2. El código incluye ejemplos de cómo definir la ecuación diferencial y las condiciones iniciales.
3. Los resultados se pueden visualizar mediante gráficos generados con matplotlib.

> **Nota:** Este es un ejemplo didáctico que puede adaptarse para resolver diferentes ecuaciones diferenciales modificando la función `f(x, y)` en el código.
