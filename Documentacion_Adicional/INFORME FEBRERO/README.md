# Informe Febrero 2025

Esta carpeta contiene scripts y datos utilizados para generar informes de mantenimiento correspondientes a febrero de 2025. Los scripts están desarrollados en Python y procesan datos en formato CSV.

## Archivos principales

- `INFORME_FEBRERO.py`: Script principal para la generación de informes.
- `Informe_Febrero_2025_rev1.py`: Versión revisada del script de generación de informes.
- `2025_febrero.csv`: Archivo de datos con información de mantenimiento.
- `2025_febrero_completo.csv`: Conjunto de datos completo con información detallada.

## Cómo usar

1. Asegúrate de tener instalado Python en tu sistema.
2. Ejecuta cualquiera de los scripts Python para generar los informes correspondientes.
3. Los scripts leerán los archivos CSV y generarán los informes en el formato correspondiente.

> **Nota:** Los archivos CSV contienen datos de ejemplo que pueden ser reemplazados según sea necesario.
