# Documentación Adicional

Esta carpeta reúne materiales complementarios, informes, ejemplos de proyectos previos y recursos de referencia que pueden servir como apoyo o inspiración para el aprendizaje de métodos numéricos y aplicaciones en ingeniería.

## ¿Qué puedes encontrar aquí?

- **Informes y reportes:** Scripts, datos y reportes generados en proyectos anteriores (por ejemplo, informes de mantenimiento, análisis de OPEX, reportes de cálculo de tuberías).
- **Ejemplos de proyectos:** Carpetas completas con código fuente, documentación y recursos de proyectos web, aplicaciones y experimentos (por ejemplo, “primavera”, “github-organizado”).
- **Herramientas y recursos web:** Archivos HTML, JS y Lua para cálculos, formularios y aplicaciones de ejemplo.
- **Manuales y referencias:** Documentos y scripts útiles para consulta o como plantilla para nuevos proyectos.

## Uso recomendado

- Explora las carpetas según el tema de tu interés. Cada subcarpeta suele contener README propio o archivos descriptivos.
- Utiliza los scripts y recursos como referencia para tus propios proyectos o para aprender buenas prácticas de documentación y organización.
- Si tienes dudas sobre el propósito de algún archivo o carpeta, consulta al docente responsable o revisa los README incluidos.

---

> **Nota:** Estos materiales no forman parte del contenido central de los capítulos, pero pueden enriquecer tu aprendizaje y servir de base para nuevos desarrollos.

## ¿Cómo usar estos recursos?

- Lee primero la guía de instalación si es tu primera vez usando Python o este proyecto.
- Consulta los tutoriales cuando quieras aprender a usar una función específica o resolver un problema.
- Si tienes dudas, revisa las preguntas frecuentes antes de pedir ayuda.
