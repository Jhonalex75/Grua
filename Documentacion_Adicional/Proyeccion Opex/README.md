# Proyección OPEX 2025

Esta carpeta contiene scripts y análisis para la proyección de gastos operativos (OPEX) para el año 2025.

## Archivos principales

- `Opex_2025.py`: Script principal para el análisis de proyección de gastos.
- `Opex_2025.txt`: Resultados del análisis en formato de texto.
- `Requerimiento_mes.py`: Script para calcular requerimientos mensuales.
- `Analisis.py` y `Analisis_1.py`: Scripts adicionales para análisis de datos.
- `robot_educator_basic.code-workspace`: Configuración de espacio de trabajo de VSCode.

## Uso

1. Asegúrate de tener Python instalado.
2. Ejecuta los scripts principales para generar las proyecciones.
3. Los resultados se mostrarán en la consola y/o se guardarán en archivos de salida.

> **Nota:** Los datos de entrada pueden necesitar actualización según los requerimientos actuales.
