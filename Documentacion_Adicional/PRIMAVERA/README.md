# Proyecto Primavera

Esta carpeta contiene una aplicación web desarrollada con Node.js y Express para la gestión de proyectos, posiblemente relacionada con el software de planificación Primavera.

## Estructura

- `primavera.js`: Archivo principal de la aplicación.
- `primavera-app/`: Aplicación web completa con frontend y backend.
- `node_modules/`: Dependencias de Node.js.
- `package.json`: Configuración del proyecto y dependencias.

## Requisitos

- Node.js
- npm (incluido con Node.js)

## Instalación

1. Instalar dependencias:
   ```
   npm install
   ```
2. Iniciar la aplicación:
   ```
   node primavera.js
   ```

> **Nota:** Este es un proyecto de ejemplo que puede requerir configuración adicional para su funcionamiento.
